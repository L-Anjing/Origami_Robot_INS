# 运动学约束的六 IMU 形态重建与输出层融合

## 问题与方法

六个面板的惯性位置属于六个不同的运动点。将这些位置用于整体定位，首先需要恢复节点间的几何关系，再转换到共同参考点S0。实验通过相邻陀螺仪恢复五个折叠角，以S0估计姿态和MJCF几何执行正向运动学，最后比较单参考、均匀和不确定度加权位置融合。

本功能为独立离线实验。原有15维ESKF、`simulation`、`real`、`export-mat`、MAT schema 2、ROS2导航/回放节点及历史fixture保持原接口。基础检查在当前本地main分支进行，起始提交、数据与fixture哈希见（旧输出已清理）。

## 数据与坐标契约

- 六个面板对应S0–S5，五个关节对应hinge0_1至hinge4_5；三路执行器只驱动其中三个关节。
- 四元数为wxyz，R_WS把传感器向量旋转到世界，世界Z向上，单位为SI。
- 记录说明规定IMU位于各plate的body原点，传感器轴与body轴重合。板体中心、body/IMU原点和端点标记分别处理。
- 前五个连接平移从XML读取，当前模型为50.1mm；实体板长50mm；V6记录的末端标记另使用50.1mm偏移。两种末端均输出误差。
- 导航初值位于t=0；首条输入为t=0.001s的步末记录。`config/shape_experiment.json`明确给出S0位置/姿态/速度、五个角度与关节速度及根角速度初值。原XML场景的root位置与日志初值分别保存，导航使用配置中有出处的日志初始位置。

正常估计模块接收`ImuMeasurements`，该类型只含时间、六路角速度和比力。`SimulationTruth`和`BiasTruth`由解析/评估分支持有，不作为关节估计或位置融合的输入。Oracle分支在评估层显式调用真实关节角，其结果以`ORACLE_`命名。

## A：可复现噪声

四个模式为`none`、`white`、`fixed_bias`、`full`；后两者依次包含白噪声+固定零偏、白噪声+固定零偏+随机游走。六个节点、每个轴独立抽样；每组关节角直接积分/静止标定后关节角积分/姿态辅助关节角估计、单IMU积分/多IMU均值融合/不确定度加权融合和Oracle复用同一带噪输入。

默认配置：

| 参数 | 数值与含义 |
| --- | --- |
| 采样间隔 | 0.001s |
| 陀螺白噪声 | 每采样点标准差0.05deg/s |
| 加计白噪声 | 每采样点标准差0.05m/s² |
| 初始陀螺零偏 | 每节点、每轴Uniform[-0.1,0.1]deg/s |
| 初始加计零偏 | 每节点、每轴Uniform[-0.02,0.02]m/s²，附加实验假设 |
| 陀螺零偏随机游走密度 | 0.003deg/s/√s |
| 加计零偏随机游走密度 | 0.001m/s²/√s |
| 种子与生成器 | seed=42，mt19937_64，显式Box–Muller |

白噪声采用积分协方差约定：连续密度为n、采样间隔为Δt时，离散测量标准差σ_sample=n/√Δt，积分噪声方差为n²Δt。默认两项白噪声的等效连续密度分别为2.75961×10⁻⁵rad/s/√Hz和1.58114×10⁻³m/s²/√Hz。

零偏更新为`b[k]=b[k-1]+n_bias√Δt ξ[k]`。`white_noise_definition=per_sample_std`读取`*_white_std_*`参数；`density`读取显式`*_white_density_*_per_sqrt_hz`参数。两种定义的等价性和随机游走的√Δt缩放均有C++测试。

这些参数描述实验扰动，不是硬件标定值。ESKF使用配置中声明的先验和过程噪声；融合不读取实际抽出的零偏真值。生成器在各消融模式消耗相同随机序列，便于分离新增噪声分量的作用。

## B：五关节估计

关节轴在子节点坐标中为u_C，子到父的固定旋转为R_PC⁰，则u_P=R_PC⁰u_C。对各自局部坐标中的角速度分别投影：

θ̇_j = u_Cᵀ(ω_C−b_gC) − u_Pᵀ(ω_P−b_gP)。

θ_j[k] = θ_j[k−1] + θ̇_j[k]Δt。

该公式适用于任意归一化轴和固定局部旋转，当前模型的Z、−Z交替轴作为一组模型实例测试。角度积分保持连续；相对姿态投影选择最接近当前角度的2π分支。

| 模式 | 状态更新与数据条件 |
| --- | --- |
| 关节角直接积分 | 使用显式初始角先验，直接积分相邻轴投影差 |
| 静止标定后关节角积分 | 使用通过初始静止窗口检验的各节点陀螺零偏，再进行积分 |
| 姿态辅助关节角估计 | 使用传感器估计的相对姿态进行铰链旋转投影，并应用关节范围与残差门控 |

姿态辅助关节角估计的相对姿态来源为各面板传感器姿态积分。将`R_PC⁰ᵀR_PC_est`分解到轴u_C，得到twist角θ_obs，按`α=1−exp(−kΔt)`进行有限增益更新。横向角速度残差和相对姿态残差用于标记失效。共享陀螺数据的相对姿态反馈是确定性约束正则化，不作为额外独立传感器观测去收缩协方差。

MJCF采用软关节限位；记录的关节角可出现下限穿透。配置保留0.08rad容差，在容差外限制角度并记录失效。范围约束不更新零偏。关节角方差是白噪声积分、初始偏置和随机游走的边缘方差代理，相邻关节共享节点陀螺，融合另记录相关性约定。

### 初始静止标定

静止标定后关节角积分检验窗口时长、每帧角速度、比力模长及样本标准差，所有节点通过后才使用均值作为陀螺零偏。加计偏置初值结合配置的初始姿态先验计算。控制位不参与静止判据。

提供的运动日志首窗含冲击，静止标定后关节角积分在四种噪声条件下均标为`unavailable`，没有静止标定后关节角积分轨迹或精度数字。C++测试使用合法静止合成窗口和节点独立偏置验证静止标定后关节角积分，并用冲击样本验证拒绝路径。若初始折叠角或S0朝向没有先验，单靠陀螺积分不能恢复其绝对初值；接口要求用户显式配置。

## C：正向运动学

对关节j，记XML子body平移为t，子body内的关节锚点为a，固定旋转为R⁰，轴为u，参考角为θ_ref：

R_PC(θ) = R⁰ Exp(u(θ−θ_ref))，

d_PC(θ) = t + R⁰a − R_PC(θ)a。

递推：

R_WC = R_WP R_PC，

r_0C = r_0P + R_WP d_PC。

因此先旋转、平移的关系由锚点方程决定。对当前零锚点模型，位置递推简化为父面板姿态旋转连接偏移。S0姿态由带噪IMU估计，正常模式不使用真实四元数。返回六个IMU/body原点、记录末端标记和实体末端位置。

程序先运行完整记录的零噪声关节角直接积分模型验收；关节误差和相对位置误差任一超过配置阈值时，保存验收结果并停止阶段D。实际最大误差分别为2.32552×10⁻⁹rad与1.53335×10⁻⁹m。

## D：六路惯性导航与输出层融合

六个`ErrorStateKalmanFilter`按同一时间戳传播，采用原仿真的步末积分。初始姿态和位置由同一配置形态通过FK生成。初始节点速度包含根平移、根旋转和各铰链转动的贡献；通用锚点实现对FK有限差分进行了测试。当前日志在t=0使用配置的静止速度先验，后续六路速度各自独立传播。

默认实验配置以陀螺积分估计各路姿态，`root_ahrs_feedback`控制原AHRS重力反馈；`navigation_zupt=none`保持无辅助对照，另支持`glrt`。这些实验开关不改变原实测导航流程。

对每个节点i：

p̂_0,i = p_INS,i − r̂_0i。

- 单IMU积分：输出S0独立INS位置。
- 多IMU均值融合：对六个p̂_0,i均匀加权。
- 不确定度加权融合：对位置协方差、参考姿态不确定度和关节角方差传播得到的形态位置不确定度代理取逆权重；失效关节下游节点降低权重。

形态敏感度为`∂r_i/∂θ_j = u_Wj × (r_i−pivot_j)`。各不确定度以标准差叠加，保留未知相关性下的迹上界代理；权重归一化后得到位置输出。ESKF协方差和关节方差本身是模型估计，因此该代理不被解释为经硬件标定的概率保证。

六路导航共享运动、先验和形态输入，当前输出层不维护完整跨节点协方差，不输出独立信息融合后的联合后验P。内部几何约束服务于节点坐标转换，全局平移和航向仍由初始先验、运动信息及外部辅助决定。

Oracle Shape仅在显式评估分支用真实关节角重建相对位置，保持带噪惯性输入、各路导航状态和S0估计姿态一致。它提供理想关节信息的受控消融，具体误差受形态误差与导航误差方向组合影响，不保证每个指标或每帧都是最小值。

## 评价与数据一致性诊断

ATE为世界系位置误差的RMSE，沿用有出处的初值，不进行轨迹拟合。RPE为1s间隔世界系位置增量误差RMSE；这里明确采用平移增量口径，不是完整SE(3)相对位姿误差。另输出五个关节的RMSE/最大/末帧误差、六面板相对位置误差、根坐标形态误差、相对及绝对末端误差、S0及六路独立姿态误差。

完整结果见（旧输出已清理）。固定零偏和随机游走条件下，形态补偿平均降低该记录的定位漂移；四种噪声条件和两种权重均完整保存。

无噪声输入审计区分三项：

1. 相邻陀螺积分和形态FK与真实构型的误差为10⁻⁹量级。
2. 各节点比力积分速度与瞬时解析FK速度的RMSE约10⁻⁸m/s。
3. 非根节点的瞬时速度与步末端点位置差分存在离散化差异，独立面板的局部角速度指数积分也带来离散姿态误差。

这解释无噪声多路融合和单根节点积分的差别，为下一阶段联合姿态约束和积分改进提供评价依据。审计只使用评估分支真值，不回写估计轨迹。

## 测试与下一阶段设计

五项CTest全部通过：

- `shape_kinematics`：静止链、单关节正反转、正负轴、初始折叠角、固定偏置理论漂移、种子复现、连续/离散噪声一致性、随机游走缩放、通用旋转轴和实际记录零噪声验收。
- `multi_imu_fusion`：五关节联合运动、通用局部旋转/锚点、初始节点速度、形态补偿、权重归一化、失效降权、平移等变及评估真值隔离。
- `shape_experiment_reproducibility`：四种噪声重复输出字节一致、初始标定拒绝、A–C失败时阻断D。
- 原`eskf`和`navigation_regression`：保留原物理检查、两份实测记录和两种完整仿真模式的回归。

输入数据、模型及历史fixture的SHA-256一致性检查见（旧输出已清理）。

下一阶段可采用六节点90维误差状态，显式维护跨节点协方差，并加入：

- 位置残差`p_i−p_0−r_0i(q_0,θ)`；
- 速度残差`v_i−v_0−ṙ_0i`；
- 相邻姿态残差`Log(R_PC(θ)ᵀ R_WPᵀ R_WC)`。

关节角可作为增广状态或与陀螺传播一并建模；共享IMU噪声和形态不确定度进入联合雅可比，避免将同一陀螺信息重复当作独立观测。配合明确的初始坐标规范，以及经验证的接触或外部位置/航向观测，进一步分析全局漂移与零偏可观测性。

# 当前工程 KF、误差传播与零偏估计

本文描述当前原生 C++ 实现。迁移前已与原 Python 实现逐帧验证，原实现现已从工程删除。

## 1. 两条独立计算链

六个 IMU 各自经过六轴 AHRS，输出六板 R_WS，结合 XML 的连接偏移累加得到相对形状。第二条链只选择一个参考 IMU，运行 Raw INS 和三个 ESKF，分别对应 none、glrt、phase。几何只用于相对形状和初始位置，不作为滤波观测。ZUPT 不回写六板形态 AHRS；参考 ESKF 的姿态、零偏是独立状态。SSIO 不属于本次重构范围。

simulated ground_truth 模式把真值姿态显式送入调试传播，冻结姿态/陀螺偏置误差自由度。estimated 才是正常估计路径；端点真值只用于评价，不能用于估计位置。

## 2. 状态与约定

名义状态 x=(p_W,v_W,q_WS,b_g,b_a)。存储维数 3+3+4+3+3=16，独立自由度15。四元数 wxyz，R_WS 将传感器系向量转到世界系；世界 Z 向上，g_W=(0,0,-g)。

滤波协方差 P 对应右乘局部误差：

δx=[δp_W,δv_W,δθ_S,δb_g,δb_a]ᵀ ∈ R¹⁵，q_true=q_nominal⊗Exp(δθ)。

注意“15维状态”准确地说是15维误差状态，不是15个名义存储数。

## 3. 名义传播

ω=ω_m−b_g，f=f_m−b_a。

先 q⁻=q⊗Exp(ωΔt)。AHRS 在比力幅值接近 g、重力创新角小于阈值、连续可靠时长足够且无冲击/量程异常时，执行重力反馈：

u=f/||f||，h=R(q⁻)ᵀe_z，c=k(u×h)，q⁺=q⁻⊗Exp(cΔt)。

a_W=R(q⁺)f+g_W，v⁺=v+a_WΔt。

仿真用步末约定 p⁺=p+vΔt+a_WΔt²；实测用常加速度 p⁺=p+vΔt+½a_WΔt²。姿态先更新，然后使用更新后的旋转计算加速度。Raw INS 使用相同的名义传播，但不传播协方差、不进行卡尔曼更新。

## 4. 当前代码实际的误差传播

它不是只把连续时间 F 简单写成 I+FΔt；它对离散姿态/AHRS 映射线性化。令 J_r 为 SO(3) 右雅可比、J_f 为重力反馈对姿态的雅可比、C 为反馈对加计零偏的雅可比：

A=J_f R(Exp(ωΔt))ᵀ，B=−J_f J_r(ωΔt)Δt，C=J_bias_feedback。

无重力反馈时 J_f=I、C=0。令 S=−R[f]×，则 Φ 的非平凡块为：

- Φ_pv=IΔt；Φ_θθ=A，Φ_θbg=B，Φ_θba=C。
- Φ_vθ=SAΔt，Φ_vbg=SBΔt，Φ_vba=(SC−R)Δt。
- Φ_p,(θ,bg,ba)=αΔt·Φ_v,(θ,bg,ba)，仿真 α=1，实测 α=½。
- p、v、bg、ba 自身块为 I；零偏名义均值在预测中保持不变。

过程噪声排列 [n_g,n_a,n_bg_rw,n_ba_rw]，共12维。G_θg=−J_f J_r，G_θa=C/Δt；G_vg=S G_θg Δt，G_va=S G_θa Δt−R；位置噪声块等于对应速度块乘 αΔt；零偏随机游走块为 I。

P⁻=ΦPΦᵀ+G diag(σ²Δt·m²) Gᵀ，随后强制对称。m 是冲击期间噪声放大倍数。这保留了同一份加速度同时驱动姿态反馈和惯性传播产生的相关项，不能在移植时分别加两份独立加计噪声。

反馈雅可比是在检测门限保持固定条件下计算，未把门限切换本身建模为连续可微过程；这是当前算法的近似。

## 5. 观测、误差注入、零偏更新位置

GLRT 在因果窗口内检查角速度和重力比力残差。phase 不是独立零速证明，而是 GLRT 候选再与三路驱动下降沿窗口取交集；none 只传播。

ZUPT: z=0，h(x)=v，H=[0 I 0 0 0]，r=−v，R_z=σ_v²I。

S_z=HP⁻Hᵀ+R_z；NIS=rᵀS_z⁻¹r，超阈值拒绝；K=P⁻HᵀS_z⁻¹；δx=Kr。

Joseph 更新 P_post=(I−KH)P⁻(I−KH)ᵀ+KR_zKᵀ。

注入：p+=δp，v+=δv，q←q⊗Exp(δθ)，bg+=δbg，ba+=δba。

所以零偏确实在每个**接受的 ZUPT** 中在线更新：δbg=K_bg r，δba=K_ba r。H 没有直接测量零偏，但传播产生的速度与零偏互协方差把速度残差分配到零偏。不是把速度硬清零，也不是对角速度做简单低通。

注入后再用 reset_θθ=J_r(δθ) 做 P←reset P_post resetᵀ。实机可对过大的位置修正将 K 的位置行置零，再执行 Joseph 更新；其他状态更新保留，不能先收缩位置协方差再丢弃位置修正。

实现位置：src/eskf.cpp 的 propagate、zupt 和 SixAxisAhrs::update；src/IMU_Processing.cpp 的 initialize 与 step。接口位于 include/eskf.hpp、src/IMU_Processing.hpp。

## 6. 当前零偏初值

仿真从 config/simulation.json 的 initial_gyro_bias_rad_s、initial_accel_bias_m_s2 读取，当前均为0。实测路径要求开头静止2秒，使用：

bg₀=mean(ω_m)，u=mean(f_m)/||mean(f_m)||，ba₀=mean(f_m)−g u。

u 同时用于 roll/pitch 对准，yaw 设为0。这个 ba₀ 主要移除比力均值的幅值误差；因为姿态也从同一个比力均值估计，横向加计偏置会与倾角耦合，不能称为完整三轴加计偏置标定。低波动、模长近 g 也无法排除所有匀速转动等伪静止情形。

六板形态 AHRS 的偏置数组默认0且固定，本身不会像参考 ESKF 那样估计零偏。更换参考节点也不是六个IMU联合估计。

## 7. 后续应如何估计零偏

1. **离线硬件标定优先**：每颗 IMU 分别记录长静止数据估计陀螺均值；加计采用至少六面/多姿态静态标定，联合拟合 bias、scale，必要时加入轴间非正交与温度项。静止单姿态不足以分离任意三轴加计偏置与倾角。
2. **保持随机游走+ZUPT 联合估计**：当前15维结构可以继续用；通过硬件静态噪声/Allan 等实验确定 noise_density 和 bias_random_walk，而不是把偏置序列抖动误当作真实温漂。
3. **可靠静止时增加零角速度观测 ZARU**：确认机体不转动后使用 ω_m=bg+n_g，残差 ω_m−bg，H_bg=I，直接约束陀螺零偏。ZUPT 本身只表示不平移，不能自动授权 ZARU。与已有检测共用同一数据时，需考虑选择偏差和噪声相关性，避免重复计入信息。
4. **多姿态或外部观测约束加计偏置**：已知静止姿态时 f_m=Rᵀ(−g_W)+ba+n_a；姿态未知时要联合建模并检查可观测性。可接视觉/动捕/GNSS等位置速度观测；折纸关节/接触约束需有可靠接触识别、外参与杆臂模型，不能把驱动关闭直接当固定锚点。
5. **六颗 IMU 的在线零偏**：独立6个滤波器或联合多刚体状态，依据观测模型选择。必须显式处理可变相对姿态及连接约束；不能把六块会相对运动的板当一个刚体做零偏平均。

仅有六轴 IMU+ZUPT 时，绝对航向、绝对位置通常仍有不可观测自由度；特定运动下部分零偏与姿态耦合。不能承诺三轴零偏都会收敛。验收应记录偏置误差/协方差、创新/NIS、静止误检率、真值误差和不同激励下的收敛；没有真值时“偏置曲线平滑”不能证明估计准确。

本次重构先保持原算法；未擅自加入未经数据验证的 ZARU 或接触观测。
